# Exact-ID graph self-composition

The candidate graph may be composed into bounded boolean powers for reachability analysis.

| Input | Rule |
|---|---|
| Vertices | inspected devices and INF entries |
| Edge | exact normalized hardware-ID match |
| Product | boolean adjacency composition |
| Limit | bounded matrix dimensions |
| Output | candidate paths, not install recommendations |

Composition never adds inferred compatibility or performs system changes.
