# Project stewardship

| Principle | Release gate |
|---|---|
| Operator intent | inspection and export are separate actions |
| Read-only | no device, driver, service, registry or firmware writes |
| Evidence | distinguish observation, inference and unknown |
| Privacy | minimize fields; disclose pseudonym/linkability limits |
| Accountability | named operator/maintainer owns decisions |
| Credibility | no fabricated compatibility, urgency or sales claims |

Workflow: inventory → evidence → comparison → review → explicit export. Changes to identity, collection or export require privacy/safety review and rollback notes.
