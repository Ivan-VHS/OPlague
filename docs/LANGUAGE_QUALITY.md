# Language and editorial quality

**Canonical shared specification:** [DuckOS — Language and editorial quality](https://github.com/Ivan-VHS/DuckOS/blob/main/docs/LANGUAGE_QUALITY.md).

Apply the shared editorial principles to English, Ukrainian, Russian and Simplified Chinese documentation, UI text, diagnostics and release notes. Keep hardware identifiers, security terms and platform names exact; automated prose checks do not replace contextual review.
