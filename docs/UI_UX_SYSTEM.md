# OPlague UI/UX

| Surface | Interaction |
|---|---|
| Inventory | read-only refresh; visible status |
| Package inspector | metadata, hashes, limits; no extraction |
| Metric Lab | JSON profiles; rejects invalid dimensions |
| Compatibility dry-run | exact ID candidates; manual review |
| Reports | scrollable, copyable, explicit export |
| Settings | versioned local theme preference |

Themes: System / Light / Dark. Keep tables resizable, data surfaces opaque, keyboard focus visible and status text explicit. Live PnP is Windows-only; saved-file analysis is portable.

## 40026 Codex

The normative six-cycle / 666-rule contract is maintained in [UI/UX Codex 40026](UI_UX_CODEX_40026.md). Light/Dark themes expose brand-compliant Success/Warning/Error/Info text roles and validate all semantic text pairs against 4.5:1 WCAG AA. Inventory and inspection remain read-only by default; no status style implies that a driver has been changed. Keyboard-only and 200% scaling remain release-level manual checks.

## UI/UX 2026 convergence

See [UI_UX_2026_CONVERGENCE.md](UI_UX_2026_CONVERGENCE.md) for shared tokens, accessibility targets, responsive behavior and motion budgets. The read-only product boundary remains authoritative.

## Anatidae desktop visual refinement

The workbench uses the shared 5 px white-blue-red identity band and theme-aware data surfaces. Device inventory rows may use subtle alternating surfaces for scanability, but selected rows and status text must remain readable. The visual layer must not imply installation, modification or certification: inspection stays read-only.
