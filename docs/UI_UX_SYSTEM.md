# OPlague UI/UX

| Surface | Interaction |
|---|---|
| Inventory | read-only refresh; visible status |
| Package inspector | metadata, hashes, limits; no extraction |
| Metric Lab | JSON profiles; rejects invalid dimensions |
| Compatibility dry-run | exact ID candidates; manual review |
| Reports | scrollable, copyable, explicit export |
| Settings | versioned local theme preference |

Theme: one fixed DAK palette with legacy preferences normalized on application. Keep tables resizable, data surfaces opaque, keyboard focus visible and status text explicit. Live PnP is Windows-only; saved-file analysis is portable.

## 40026 Codex

The normative six-cycle engineering contract is maintained in [OPlague UI/UX Profile — Stage 0.5](UI_UX_PROFILE_STAGE_0_5.md). The fixed palette exposes distinct Success/Warning/Error/Info text roles and validates all semantic text pairs against 4.5:1 WCAG AA. Inventory and inspection remain read-only by default; no status style implies that a driver has been changed. Keyboard-only and 200% scaling remain release-level manual checks.
