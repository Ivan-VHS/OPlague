# Mora Amber theme profile — OPlague

**Maintainer:** Ivan-VHS

OPlague's default theme is now Mora Amber. The existing System, Light and Dark profiles remain selectable and persisted through the same atomic settings store. The setting can also be selected with `OPLAGUE_UI_THEME=mora`.

## Semantic palette

| Role | Value |
|---|---|
| Workspace | `#211913` |
| Main panel | `#33261D` |
| Raised panel | `#493326` |
| Primary text | `#FFF3E2` |
| Supporting text | `#E7D2B8` |
| Muted text | `#C4A98A` |
| Main action | `#D58B3D` |
| Hover / focus | `#EAA653` / `#F3C16B` |
| Critical state | `#B64A40` |
| Muted olive | `#526347` |
| Selection | `#60442E` |
| Diagnostic log | `#18120D` |

Amber represents normal actions. Red remains reserved for critical/destructive states. Diagnostic logs, hashes, package metadata and evidence tables stay opaque and readable.

## Composition and motion

Use stable work areas and clear panel boundaries; do not cover inventory or evidence with decoration. The warm profile uses the shared 8 px spacing rhythm, restrained focus feedback and existing motion preferences. Reduced Motion and Eco remain authoritative.

## Safety boundary

The theme changes appearance only. Device inventory, package analysis, signature review and evidence handling remain read-only.
