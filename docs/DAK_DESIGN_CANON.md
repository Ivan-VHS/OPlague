# Dak design canon

The shared desktop baseline uses clear semantic tokens while each native application keeps its own information architecture, toolkit and product identity. Dak system surfaces use a black, white and gold foundation; status colors remain reserved for explicit success, warning, error and information states.

| Token | Value | Use |
|---|---|---|
| Canvas | #070707 | Main workspace |
| Surface | #101010 | Primary panels |
| Elevated | #181818 | Secondary panels |
| Text | #FFFFFF | Primary content |
| Secondary | #E5E5E5 | Supporting copy |
| Muted | #A6A6A6 | Metadata |
| Action | #FFD400 | Primary actions and selection |
| Hover / focus | #FFE45C | Pointer and keyboard focus |
| Success | #2EAD68 | Successful state |
| Warning | #FFD400 | Caution |
| Error | #FF6B72 | Failure |
| Information | #6CA8FF | Neutral technical information |

Text and icon labels always accompany color. Preserve WCAG contrast, visible keyboard focus, native controls, reduced-motion behavior and readable opaque work surfaces. No external runtime assets or cloud fonts are required.
