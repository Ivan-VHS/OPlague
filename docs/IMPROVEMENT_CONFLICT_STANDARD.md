# Improvement and conflict resolution

The machine-readable `improvement-conflict.v1.json` retains 20 canonical triplets and explicit evidence states.

| Step | Gate |
|---:|---|
| 1 | record reproducible symptom |
| 2 | confirm root cause |
| 3 | define bounded change + rollback |
| 4 | implement on a branch |
| 5 | test and review exact head |
| 6 | merge only after protection/checks |

A conflict term is diagnostic vocabulary, not proof of a defect.
