# Unified Documentation and Semantics Standard

**Canonical specification:** [DAK — Unified Documentation and Semantics Standard](https://github.com/Ivan-VHS/DAK/blob/main/docs/UNIFIED_DOCUMENTATION_STANDARD.md).

Use the shared vocabulary for implementation maturity, runtime state, verification outcome, integration policy and evidence. OPlague source, tests, schemas, the release workflow and SECURITY.md remain authoritative for device/package inspection and security boundaries.

The shared policy includes the 50-point README publication checklist for identity, release provenance, architecture/contracts, breaking changes, limitations, reproducible evidence, localization, navigation, legal attribution and clean-environment verification. See [Documentation Control](DOCUMENTATION_CONTROL.md) for OPlague-specific gates.
