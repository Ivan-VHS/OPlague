# Orthogonal metric diagnostics

Input is operator-supplied normalized JSON profiles; no undocumented device counters are probed.

| Metric | Use |
|---|---|
| Euclidean / weighted distance | profile separation |
| Dot / cosine / angle | directional similarity |
| Orthogonality | numerical relation, not independence proof |
| Mean / sample variance | repeated-run spread |
| Variance composition | only when covariance is zero |

Dimensions, finite values and weights are validated. Results are analysis, not vendor certification or driver ranking.
