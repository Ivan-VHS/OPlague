# OPlague DuckOS visual system

OPlague uses the same fixed black, white and duck-yellow palette as DuckOS and Mora.

| Role | Value |
|---|---|
| Background | `#080808` |
| Primary surface | `#151515` |
| Elevated surface | `#242424` |
| Main text | `#FFFFFF` |
| Supporting text | `#E5E5E5` |
| Muted text | `#A6A6A6` |
| Action / accent | `#FFD400` |
| Hover / focus | `#FFE45C` |
| Border | `#3A3A3A` |
| Selection | `#3A3100` |

There is one palette and no system/light/dark cycle. Existing configuration is migrated to the `duck` mode on the next theme application. UI text, icons and accessible labels continue to identify success, warning and error states; color is never their only signal.

OPlague remains a read-only device and driver workbench. Changing the palette does not install drivers, alter devices, change performance settings or write to hardware.
